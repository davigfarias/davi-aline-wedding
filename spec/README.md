# Convite Davi & Aline

Landing page do convite de casamento, reproduzindo o convite impresso.

```bash
python3 -m http.server 8000   # http://localhost:8000
```

Sirva por HTTP: pelo `file://` a fonte e o módulo ES são bloqueados por CORS.

As regras de design (paleta, fontes, ornamentos, o que não mudar) estão em
`CLAUDE.md`. Leia antes de alterar qualquer coisa visual.
